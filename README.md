# AussieInternetArchive
Archiving the Australian Internet onto the Internet Archive.

## What does this do?
Runs an automation every day at 00:00 UTC through GitHub Automations to back up selected websites to the [Internet Archive](http://archive.org).

## How do I add some sites?
Easy! Open an issue with the sites you want to add, or if you're technical, open a PR!
